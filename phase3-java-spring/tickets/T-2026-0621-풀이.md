# T-2026-0621 풀이 — 공지사항 상세 보기 추가 (졸업 기준표 14번)

형태 ② 프로젝트 투입. **새로 짓지 않고 목록을 본떠** 다섯 칸에 붙였다. 순서는 아래(XML)에서 위(Controller)로.

## 다섯 칸 (사용자가 직접 작성)

```xml
<!-- ① BbsMapper.xml -->
<select id="selectBbs" parameterType="int" resultType="map">
    SELECT ntt_id AS "nttId", ntt_sj AS "nttSj", ntt_cn AS "nttCn", ntcr_nm AS "ntcrNm"
         , TO_CHAR(frst_regist_pnttm, 'YYYY-MM-DD') AS "frstRegistPnttm"
      FROM comtnbbs
     WHERE ntt_id = #{nttId}
       AND use_at = 'Y'          ← 목록의 규칙을 그대로 가져간다 (삭제된 글 차단)
</select>
```

```java
// ② BbsMapper.java       — Service 가 부르는 약속
Map<String, Object> selectBbs(int nttId);

// ③ BbsService.java      — Controller 가 부르는 약속 (메뉴판)
Map<String, Object> selectBbs(int nttId);

// ④ BbsServiceImpl.java  — 실제 일 (주방)
public Map<String, Object> selectBbs(int nttId) {
    Map<String, Object> bbs = bbsMapper.selectBbs(nttId);
    if (bbs == null) {                                   ← 목록에 없던 경우 : 없는 글
        throw new ResponseStatusException(HttpStatus.NOT_FOUND, "없는 게시물입니다");
    }
    return bbs;
}

// ⑤ BbsController.java   — 주소표
@GetMapping("/bbs/selectBbs.do")
public Map<String, Object> selectBbs(@RequestParam int nttId) {
    return bbsService.selectBbs(nttId);
}
```

## 짝 맞추기 — MyBatis 의 전부

```
XML   <select id="selectBbs" parameterType="int" resultType="map">
Java  Map<String, Object>   selectBbs(        int nttId);
      ↑ resultType = 나가는 것  ↑ id = 이름      ↑ parameterType = 들어오는 것
```

| 실수 | 결과 |
|---|---|
| `parameterType` 대신 `resultType` 을 바꿈 | 들어오는 것과 나가는 것이 뒤바뀐다 |
| `parameterType="BoardVO"` | BoardVO 에 nttId 칸이 없어서 MyBatis 에러 |
| SELECT 에 `nttCn` (별칭) 을 씀 | DB 칸 이름은 `ntt_cn`. 왼쪽 = DB 칸, 오른쪽 AS = 자바 이름표 |
| `selectbBs` (한 글자 오타) | 자바는 대소문자가 다르면 다른 이름 → `cannot find symbol` |

## 완료 조건

```
nttId=3     내용까지 나옴                                    ✓
nttId=26    ==> Parameters: 26(Integer)  <== Total: 0  → 404   ✓  DB 에는 있지만 use_at='N'
nttId=999   404                                               ✓
```

로그의 `parameters={masked}` 는 스프링이 요청값을 일부러 가린 줄 (개인정보 보호 기본값). SQL 은 `==> Parameters:` 줄을 본다.

## 공공 DB 칸 이름 약어

```
_SJ 제목   _CN 내용   _NM 이름   _AT 여부(Y/N)   _PNTTM 시점   _DE 일자   _SE 구분   _CNT 건수   _ID 아이디
```

## 3줄

1. 목록의 다섯 칸을 아래(XML)부터 위(Controller)로 하나씩 본떠 붙인다
2. 이름과 모양의 짝을 맞춘다 — XML id = 메서드 이름 / parameterType = 받는 것 / resultType = 돌려주는 것
3. 목록의 규칙은 그대로 가져가고(use_at), 목록에 없던 경우는 새로 막는다(없는 글 → 404)
