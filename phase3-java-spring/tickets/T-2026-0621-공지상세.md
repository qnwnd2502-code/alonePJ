## 관계도 — 전부 발주처 소스, 우리가 얹는다

```
브라우저 ─▶ BbsController ─▶ BbsService(약속) ─▶ BbsServiceImpl ─▶ BbsMapper(약속) ─▶ BbsMapper.xml ─▶ DB comtnbbs
           (주소표)          (인터페이스)        (실제 일)         (인터페이스)        (SQL)
```

## ★ 규칙 : 새로 짓지 말고 '목록' 을 본떠라

현장에서는 내 스타일대로 짜지 않는다. **옆에 있는 기능을 그대로 본떠** 같은 모양으로 붙인다.
다음 사람이 읽을 때 목록과 상세가 같은 모양이어야 한다.

전자정부 이름 관례 :

```
selectXxxList     목록         ← 이미 있다
selectXxxListCnt  목록 건수     ← 이미 있다
selectXxx         상세 (1건)    ← 이번에 만든다
insertXxx / updateXxx / deleteXxx
```

## 지도 — 본뜰 곳 5군데

| # | 파일 | 본뜰 것 (이미 있는 목록) | 새로 만들 것 |
|---|---|---|---|
| 1 | `src/main/resources/mapper/bbs/BbsMapper.xml` | `<select id="selectBbsList">` | `<select id="selectBbs">` |
| 2 | `src/main/java/com/study/bbs/BbsMapper.java` | `selectBbsList(...)` 한 줄 | `selectBbs(...)` 한 줄 |
| 3 | `src/main/java/com/study/bbs/BbsService.java` | `selectBbsList(...)` 한 줄 | `selectBbs(...)` 한 줄 |
| 4 | `src/main/java/com/study/bbs/BbsServiceImpl.java` | `selectBbsList` 메서드 | `selectBbs` 메서드 |
| 5 | `src/main/java/com/study/bbs/BbsController.java` | `selectBbsList` 메서드 | `/bbs/selectBbs.do` 메서드 |

**순서는 아래(1, DB 쪽)에서 위(5, 화면 쪽)로.** 아래가 없으면 위가 컴파일되지 않는다.
