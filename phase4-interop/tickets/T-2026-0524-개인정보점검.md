> 개발 시 요구사항 **SFR-PII-04 "상담 질문은 개인정보를 가린 뒤에만 로그에 남기고 외부로 보낸다"** 를

>
> 또 AI 상담은 **외부 LLM(클라우드 업체)** 을 쓴다고 들었습니다. 주민번호가 **기관 밖으로 나갔는지** 가 가장 걱정입니다.
>
> 아래 세 가지를 회신해 주세요.
> 1. 주민번호가 **남아 있거나 나간 곳** 목록
> 2. 원인
> 3. 조치 (고친 것 + 이미 남은 것을 어떻게 할지)

## 화면

```
http://localhost:9600/counsel.html      예시 A·B·C 버튼 = 점검 기간 민원 원문 발췌 (번호는 전부 가짜)
```

## 값이 지나가는 길 (인수인계 메모)

```
화면 counsel.html
   ↓ POST /counsel/ask
기관 백엔드   CounselController.java   (+ MaskingUtil.java)      ← 기관 서버
   ↓ 방화벽 VIP 10.20.30.100:443
우리 AI 제품  agenthub/app.py  /ai/counsel                             ← 우리 서버
   ↓
외부 LLM API  llm-ext                                               ← 남의 회사 서버 (인터넷 건너편)
```

## 확인 도구 — 네 군데

```
① 화면        상담하기 결과창
② 기관 로그   docker compose logs boot --since 5m | Select-String counsel
③ 우리 로그   docker compose logs agenthub --since 5m
④ 외부 LLM    docker compose logs llm-ext --since 5m
```

※ ④ 는 학습용 창문이다. **현실에서는 업체 로그를 우리가 못 본다.**
　 그래서 "안 나갔다" 는 걸 증명하려면 ② ③ 에서 증명해야 한다.

★ 목표 : 예시 A·B·C 각각 **네 군데 중 어디에 번호가 그대로 남는지** 표로 채우고, 원인 줄을 짚는다.
