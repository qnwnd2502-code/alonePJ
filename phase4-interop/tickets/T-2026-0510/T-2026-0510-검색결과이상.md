## 첨부 1 — 포털 AI 검색 화면 (OO공단 정보화팀 작성, JSP 발췌)

```jsp
<%-- 로그인한 사용자 정보는 세션의 loginVO 에 있다 --%>
<form action="/portal/ai-search" method="get">
    <input type="hidden" name="userId" value="${loginVO.id}">
    <input type="text"   name="q" placeholder="무엇이든 물어보세요">
    <button>검색</button>
</form>
```

## 첨부 2 — 포털 백엔드 (OO공단 정보화팀 작성)

```
src/main/java/com/study/interop/PortalController.java
```

## 첨부 3 — 우리 AI 서버의 연계 규격 (우리가 OO공단에 준 것)

```
GET /ai/search?q=검색어
헤더  X-User-Id : 사용자 ID     ← 이 사용자의 부서 문서만 검색한다
```

AI 서버 코드 : `aisvc/app.py` 의 `/ai/search`

## 확인 도구 (브라우저로)

```
로그인      http://localhost:9600/portal/login?user=kim
검색        http://localhost:9600/portal/ai-search?userId=kim
로그아웃     http://localhost:9600/portal/logout
```

`/portal/ai-search` 는 **화면의 검색 폼이 보내는 요청을 그대로 흉내낸 것**이다.
브라우저 주소창의 값이 곧 폼이 보내는 값이다.
