## 함정과 원리

| 줄 | 함정 | 원리 |
|---|---|---|
| 1·2 | 포털 VIP(.10)를 출발지로 / 1호기만 적기 | **VIP 는 받는 창구.** 밖으로 거는 건 서버 자신의 주소. 이중화면 **호기마다 한 줄** — 한 줄만 쓰면 L4 가 나눠준 절반만 실패("가끔 안 돼요") |
| 3 | 포트 8000 (질의 문) / VIP 로 보내기 | 원격 유지보수는 ssh **22**. VIP 는 443 만 8000 으로 넘겨준다 → AI 서버 실제 주소로 |
| 3 | `/24` | 앞 세 덩어리 고정, 마지막 0~255 = 256개 주소. VPN 사용자 여러 명이 각자 받는 대역 |
| 4 | 방향 거꾸로 | **먼저 거는 쪽이 출발지.** AgentHub 가 문서를 가져가러 간다 → AI 서버가 출발지 |
| 4 | 출발지에 AI VIP(.100) | 1·2 와 같은 원리. 나갈 때는 서버 자신의 주소(172.30.0.20) |
| 4 | 사용기간 "요청 시" | 수집은 매일 밤 자동 배치. **사람이 쓰는 통로는 요청 시, 프로그램이 쓰는 통로는 상시** |
| 전부 | 사용기간 | 만료일이 지나면 어느 날 갑자기 막힌다(실습 19). 유지보수 계약 기간에 맞춘다 |

## VPN 은 방화벽이 세 겹

```
반디SNC PC ──①──▶ 인터넷 ──②──▶ 기관 VPN 장비 ══터널══▶ 10.99.1.x ──③──▶ AI 서버:22
① 반디SNC 사내 방화벽 : 기관 VPN 장비 공인IP:443 나가기     ← 우리 회사 보안팀에 우리가 신청
② 기관 VPN 장비      : 반디SNC 공인 IP 접속 허용            ← 기관에 우리 공인 IP 를 알려준다
③ 기관 내부 방화벽    : VPN 대역 → AI 서버:22                ← 위 신청서 3번
+ VPN 계정·OTP, VPN 클라이언트
```

## 개통 전 기관에 요청할 것 (요청문)

| # | 요청 항목 | 왜 필요한가 |
|---|---|---|
| 1 | AI 서버 사양 — `nvidia-smi` 결과(GPU·VRAM·드라이버/CUDA), OS·도커 버전, 디스크 여유 | 모델이 GPU 에 안 올라가면 개통 불가(실습 20). 모델 파일만 수십 GB(실습 18) |
| 2 | 원격 접속 수단 — VPN 계정·OTP, VPN 허용 IP 에 반디SNC 공인 IP 등록, AI 서버 ssh 계정 | 없으면 개통 후 장애가 나도 들어갈 수 없다 |
| 3 | 문서 서버 수집 계정 — 공유폴더 **읽기 전용**, **수집 전용** 계정 | 없으면 수집 0건. 개인 계정이면 퇴사·비번 변경 날 수집이 멈추고, 권한이 너무 넓다(실습 8) |

수집 계정 비밀번호는 AgentHub 설정에 넣되 **평문 금지** — 환경변수·암호화 저장.
