## 확인 도구

```
폐쇄망 서버 흉내    docker compose run --rm offline-dev <명령>
                   ★ 네트워크가 아예 없는 컨테이너다. usb 폴더만 /usb 로 보인다
                   ★ 서버 사양(첨부 2)과 같은 python:3.12 리눅스다

예) 설치 시도      docker compose run --rm offline-dev sh -c "pip install --no-index --find-links wheels -r aisvc/requirements.txt"
```

`--no-index` = "인터넷(PyPI)에서 찾지 마라", `--find-links wheels` = "이 폴더에서만 찾아라". 폐쇄망 설치의 기본형이다.
