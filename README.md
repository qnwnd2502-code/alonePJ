# alonePJ

주니어에서 시니어 상위급 개발자로 성장하기 위한 18~24개월 학습 프로젝트.

혼자 진행하지만 **팀 협업을 가정한 워크플로**(feature 브랜치 → PR → 리뷰 → 머지)를 그대로 따른다.

## 실무 배경

공공기관 대상 SI 프로젝트 / **전자정부 표준프레임워크(eGovFrame)** 환경.
→ Java · Spring · MyBatis · JSP · Maven 이 매일 만지는 스택이므로 학습 우선순위를 여기에 맞춘다.

## 로드맵

| Phase | 기간 | 주제 | 상태 |
|-------|------|------|------|
| 1 | ~2개월 | Git + Docker 협업 기초 | 진행 중 |
| 2 | 2~6개월 | **Java · Spring · eGovFrame 코드 독해** | 예정 |
| 3 | 6~9개월 | HTTP/HTTPS · 웹 아키텍처 · 공공 보안 요건 | 예정 |
| 4 | 9~13개월 | Python 코드 독해 + 데이터 처리 | 예정 |
| 5 | 13~18개월 | AI 개발 심화 (LLM · RAG · 에이전트) | 예정 |
| 6 | 18~24개월 | 시스템 설계 · DevOps · 레거시 현대화 | 예정 |

> Java를 앞으로 당긴 이유: 실무에서 매일 읽는 코드가 eGovFrame(Spring 기반)이라,
> 여기서 독해력이 붙어야 나머지 학습 속도가 전부 빨라진다.

## 구조

```
phase1-git-docker/    Git 브랜치 전략 · Docker 컨테이너 실습
```

Phase가 진행되면 폴더가 추가된다.

## 규칙

- `main` 브랜치에 직접 커밋하지 않는다. 반드시 feature 브랜치 → PR을 거친다.
- 커밋 메시지는 `타입: 요약` 형식을 쓴다. (`feat`, `fix`, `docs`, `chore`, `refactor`)
- 비밀키·토큰은 절대 커밋하지 않는다.
